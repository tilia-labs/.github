# tilia

tilia is an async UX research tool for solo researchers, designers and small teams. Run tree tests, card sorts, first-click tests, five-second tests, preference tests and surveys, free to start.

## Free templates

[ux-research-templates](https://github.com/tilia-labs/ux-research-templates) has ready-to-run tree test and card sort templates you can upload to tilia and have live in about five minutes.
